# Demonstration Videos

*English below · [日本語は下段へ](#ja)*


Screen recordings of the civicship front end, one per use case, at a 390×844
mobile viewport. Milestone 5, deliverable 3. Project Catalyst F12, Project ID
1200088.

They are split so that a reviewer can see two things separately: that what
Milestone 3 demonstrated still works, and what the platform has gained since.

| | |
| --- | --- |
| [**Milestone 3 use cases**](./milestone3-use-cases/) | The same eleven use cases Milestone 3 demonstrated — eight for a resident, three for a host — recorded again on the application as it stands today |
| [**Added since Milestone 3**](./added-since-milestone3/) | Nine capabilities the platform gained afterwards, with no overlap with the set above. Two of them carry the Cardano work directly: issuing a verifiable credential, and the resident-card NFT with its holder's DID and token standard |

Each directory's README lists its videos and states the recording conditions.

# デモ動画

*[English is above](#en)*

civicship のフロントエンドの画面録画。ユースケース1件につき1本、390×844 のモバイル表示。
Milestone 5 成果物3。Project Catalyst F12、Project ID 1200088。

レビュアーが2つのことを別々に確認できるよう、2つに分けている — Milestone 3 で
デモンストレーションしたものが現在も動作すること、そしてそれ以降に何が増えたか。

| | |
| --- | --- |
| [**Milestone 3 のユースケース**](./milestone3-use-cases/) | Milestone 3 でデモンストレーションした同じ11件（住民向け8件・ホスト向け3件）を、現在のアプリケーションで撮り直したもの |
| [**Milestone 3 以降に追加された機能**](./added-since-milestone3/) | その後に増えた9件。上記と重複はない。うち2件が Cardano の実装に直結する — 検証可能な資格情報（VC）の発行と、保有者DID・トークン規格を伴う住民証NFT |

各ディレクトリの README に、収録動画の一覧と録画条件を記載している。
