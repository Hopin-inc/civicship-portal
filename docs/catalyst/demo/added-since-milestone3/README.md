Milestone 3 playlists; the use cases that do are recorded in

Milestone 5, deliverable 3. Project Catalyst F12, Project ID 1200088.

| | Use case | Video |

[that README](../milestone3-use-cases/README.md#what-to-know-when-watching).

# Milestone 3 以降に追加された機能

*[English is above](#en)*

Milestone 3 以降にプラットフォームが獲得した機能。いずれも Milestone 3 のプレイリストには
含まれていない。含まれていたユースケースは
[`../milestone3-use-cases`](../milestone3-use-cases/) に収録している。

Milestone 5 成果物3。Project Catalyst F12、Project ID 1200088。

| | ユースケース | 動画 |
| --- | --- | --- |
| ① | 募集を新しく作る | [`E1_create-opportunity.mp4`](./E1_create-opportunity.mp4) |
| ② | メンバーと権限を管理する | [`E2_manage-members.mp4`](./E2_manage-members.mp4) |
| ③ | ポイントを発行し、メンバーに付与する | [`E3_issue-points.mp4`](./E3_issue-points.mp4) |
| ④ | 拠点を登録する | [`E4_register-place.mp4`](./E4_register-place.mp4) |
| ⑤ | 参加証明（VC）を発行する | [`E5_issue-credential.mp4`](./E5_issue-credential.mp4) |
| ⑥ | 住民証NFTを管理する | [`E6_resident-nfts.mp4`](./E6_resident-nfts.mp4) |
| ⑦ | 特典を設定する | [`E7_configure-bonuses.mp4`](./E7_configure-bonuses.mp4) |
| ⑧ | コミュニティ財布にポイントを拠出する | [`E8_contribute-points.mp4`](./E8_contribute-points.mp4) |
| ⑨ | 確定した参加内容を確認する | [`E9_confirm-participation.mp4`](./E9_confirm-participation.mp4) |

このうち2件が Cardano の実装に直結する。**⑤** は参加者への検証可能な資格情報（VC）の発行、
**⑥** は住民証NFTの保有者DID・コントラクトアドレス・トークン規格の表示である。

録画の条件は Milestone 3 のセットと同じ。
[そちらの README](../milestone3-use-cases/README.md#視聴にあたって) を参照。
